**[English version](README.en.md)**

Сайт с живым списком узлов, статистикой и инструкциями: **https://sakazxc1400-creator.github.io/free-vpn-sub/**

Бесплатная подписка с VPN-серверами, которая обновляется каждый час.

Скрипт собирает конфиги из открытых источников на GitHub, проверяет их и оставляет только рабочие серверы. В названии каждого сервера указаны страна, протокол и задержка.

Есть три версии подписки:

* основная, примерно 200 самых быстрых серверов;
* стабильная, только те серверы, что отвечают несколько прогонов подряд, обычно от 30 до 100;
* полная, все серверы, которые прошли проверку, обычно больше 1000.

Основная подписка быстрее загружается и подходит для повседневного использования. Стабильная медленнее обновляется, зато её серверы не пропадают через час. Полная пригодится, если в основной версии ничего не подключается или хочется выбрать сервер вручную.

Поддерживаются VLESS, включая Reality, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC. Для Clash и Mihomo есть готовый конфиг.

## Что находится в списке

Серверы идут от самых быстрых к самым медленным. Пример:

```
01. 🇭🇰 Гонконг · vmess · 211ms · 12ч
02. 🇵🇱 Польша · ss · 288ms
03. 🇬🇧 Британия · ss · 301ms · 8ч
04. 🇳🇱 Нидерланды · ss · 311ms
05. 🇷🇺 Россия · vless · 340ms · 26ч
```

Число в конце вроде `12ч` показывает, сколько часов подряд сервер отвечает в наших прогонах. У новых узлов этой отметки ещё нет.

Знак `⚠` означает, что узел пропускает трафик, но не прошёл проверку HTTPS-сертификата: он может подменять сертификаты и читать содержимое соединений. Такие узлы попадают только в полную подписку.

В основной подписке от одной страны может быть не больше 12 серверов. Это помогает не получить список, состоящий почти целиком из одного датацентра. В полной подписке такого ограничения нет.

В основной подписке серверы идут по качеству: сначала проверенные по сертификату, внутри группы сначала те, чья скорость измерена, потом по скорости, затем по задержке. Список собирается по задержке с оглядкой на страны, а замер скорости уточняет порядок в нём. Сами замеры лежат в `output/nodes.json`.

## Как подключиться

### Windows

Самый простой вариант, [Nekoray](https://github.com/MatsuriDayo/nekoray/releases). Скачайте архив `nekoray-*-windows64.zip`, распакуйте его и запустите `nekoray.exe`.

1. Откройте настройки и выберите ядро `sing-box`.
2. Перейдите в раздел добавления профиля из подписки и вставьте ссылку.
3. Обновите подписки.
4. Выберите сервер в верхней части списка и нажмите `Enter`.
5. Нажмите `Ctrl+Alt+S`, чтобы включить системный прокси.

Также можно использовать [v2rayN](https://github.com/2dust/v2rayN/releases). Ссылка добавляется в разделе «Подписки».

### Android

Подойдут [v2rayNG](https://github.com/2dust/v2rayNG/releases) и Hiddify.

1. Откройте меню слева и перейдите в настройки групп подписок.
2. Нажмите `+`, вставьте ссылку и сохраните её.
3. Откройте меню справа и обновите подписки.
4. Выберите сервер и нажмите кнопку подключения.

[Hiddify](https://github.com/hiddify/hiddify-next/releases) особенно удобен для протоколов Hysteria2 и TUIC. В нём подписка добавляется через `+` и пункт «Добавить из ссылки».

### iPhone и iPad

Можно использовать Streisand, v2Box или Shadowrocket. Первые два приложения бесплатные, Shadowrocket платный.

Откройте раздел подписок, нажмите `+`, вставьте ссылку, обновите список и выберите сервер.

### macOS

Попробуйте [Hiddify](https://github.com/hiddify/hiddify-next/releases) или V2RayXS. Добавьте подписку по ссылке, обновите список и подключитесь к серверу.

### Linux

Подойдут [Nekoray](https://github.com/MatsuriDayo/nekoray/releases) и [Hiddify](https://github.com/hiddify/hiddify-next/releases) в формате AppImage.

## Если что-то не работает

**Сервер подключился, но интернета нет.** Сервер мог перестать работать или достигнуть лимита уже после проверки. Попробуйте следующий сервер в списке.

**Не работает ни один сервер.** Обновите подписку в приложении. Список меняется каждый час.

**Подписка не загружается.** Используйте зеркало выше. Если оно тоже недоступно, скачайте `output/all.txt` и импортируйте содержимое из буфера обмена.

**Соединение медленное.** Бесплатные серверы иногда перегружены. Начните с верхних строк списка. На нестабильном интернете Hysteria2 часто работает лучше других протоколов.

## Как всё работает

```
sources.txt     список источников
collect.py      скачать, разобрать, проверить и сохранить конфиги
outbound.py     преобразовать ссылки в конфиг sing-box
probe.py        проверить, проходит ли через сервер трафик, сертификат и скорость
clashout.py     собрать конфиг Clash и Mihomo из проверенных узлов
notify.py       отправка итогов прогона в Telegram
geo.py          определить страну по IP
mirror/         зеркало подписки на Cloudflare Workers
output/         готовые списки
docs/           сайт для GitHub Pages
```

Каждый час GitHub Actions запускает сборку.

Сначала скрипт параллельно скачивает источники, повторяя запрос до трёх раз. Он понимает обычный текст и base64, находит ссылки и отбрасывает мусор: битые адреса, localhost, приватные подсети и неправильные порты.

Затем одинаковые серверы объединяются. Один адрес часто встречается в нескольких источниках под разными именами. После этого остаётся больше 20 тысяч уникальных кандидатов.

Проверка проходит в два этапа. Сначала скрипт быстро проверяет TCP-подключение и убирает явно недоступные адреса. Потом sing-box запускает локальный прокси для каждого кандидата и отправляет через него запрос к `generate_204`. Пустой ответ со статусом 204 означает, что сервер действительно пропустил трафик в интернет и вернул ответ.

Узлы проверяются несколькими процессами sing-box одновременно, поэтому за отведённое время успевает пройти проверку больше кандидатов.

Hysteria2 и TUIC работают через QUIC, поэтому TCP-проверка для них не используется. Они сразу переходят ко второму этапу.

Перед проверкой отсеиваются конфиги, на которых sing-box падает целиком и уносит с собой весь батч: неизвестный отпечаток uTLS (часто встречается `unsafe`), битый ключ Reality, TUIC без корректного UUID, shadowsocks-2022 с ключом неверной длины и выдуманный шифр VMess. Такой узел всё равно бы не заработал, а без отсева он мешал проверить соседей.

После проверки скрипт определяет страну сервера, измеряет задержку и сортирует результаты. Полный список получает все рабочие серверы, а основная подписка берёт лучшие из них с ограничением по странам.

Дальше каждый живой узел проходит проверку HTTPS: скрипт подключается через него к сайтам с известными сертификатами и проверяет сертификат полностью. Если узел подсовывает свой сертификат, значит он читает содержимое соединений. Такой узел остаётся только в полной подписке и помечается знаком `⚠`.

Для каждого узла основной подписки измеряется скорость: через узел скачивается небольшой файл, и результат в мегабитах в секунду попадает в `output/nodes.json`. В тексте подписки скорость не пишется, чтобы не раздувать список.

Прогоны связаны между собой через `output/history.json`. Скрипт считает, сколько прогонов подряд узел отвечает, и запоминает это число. Узлы, живущие много часов, попадают в отдельную стабильную подписку: обычно это самые надёжные серверы списка.

Если сборка получилась заметно хуже предыдущей, меньше 60% от прошлого числа серверов, скрипт не перезаписывает подписки и завершается с ошибкой. Так сбой на стороне источников не оставит вас с пустым списком. Обойти защиту можно переменной `ALLOW_SHRINK=1`, если падение честное.

Серверы с одинаковым адресом и портом объединяются в один, остаётся самый быстрый. Один и тот же узел часто лежит в источниках десятком копий с разными uuid, и без этого подписка заполнялась бы дублями.

Если источники недоступны или проверку не прошёл ни один сервер, старые файлы не удаляются. Рабочая подписка со старыми данными лучше пустого списка.

### Уведомления в Telegram

Прогон может присылать итог в Telegram: сколько серверов нашлось, какие страны в списке, что изменилось. Функция выключена, пока не заданы секреты.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и возьмите токен.
2. Напишите своему боту любое сообщение и узнайте свой id у [@userinfobot](https://t.me/userinfobot).
3. В настройках репозитория, в разделе `Settings` → `Secrets and variables` → `Actions`, добавьте секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

Проверить вручную можно так:

```bash
TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... python notify.py "проверка связи"
```

### Зеркало подписки

Если GitHub в вашей сети недоступен, поднимите зеркало на Cloudflare Workers: файлы те же, а домен Cloudflare обычно открыт. Готовый код и пошаговая инструкция лежат в [`mirror/`](mirror/README.md). Бесплатного тарифа хватает с запасом, ставить ничего не нужно, всё делается в браузере.

### Запуск на своём компьютере

```bash
python selftest.py     # проверить парсеры
python testconv.py     # проверить конвертер ссылок и определение страны
python testclash.py    # проверить сборку конфига Clash
python testsingbox.py  # проверить конфиги, нужен sing-box
python e2etest.py      # запустить полный тестовый сценарий
python collect.py      # собрать подписку
```

Нужен Python 3.9 или новее. Дополнительные библиотеки не требуются, для `testclash.py` желателен `pyyaml`: без него тест проверит YAML своими глазами. Для полной проверки серверов положите рядом с файлами бинарник [sing-box](https://github.com/SagerNet/sing-box/releases). Если его нет, скрипт выполнит только TCP-проверку и сообщит об этом в логе.

### Как добавить свой источник

Добавьте ссылку в `sources.txt` на отдельной строке. Строки, начинающиеся с `#`, считаются комментариями. Формат источника определяется автоматически.

## Важно о безопасности

Перед использованием прочитайте этот раздел.

Владелец сервера может видеть ваш трафик. Эти серверы запускают неизвестные люди, и мы не знаем, как они с ним обращаются. Оператор может узнать, какие сайты вы посещаете. При подмене сертификата он также сможет перехватывать содержимое соединений.

Поэтому каждый узел дополнительно проверяется HTTPS-запросом с полной проверкой сертификата. Узел, который подменяет сертификаты и читает содержимое соединений, в основную подписку не попадает: в полной он помечен знаком `⚠`. Это снижает риск, но не отменяет его полностью: владелец сервера всё равно видит, к каким сайтам вы подключаетесь.

Не используйте такие серверы для банковских приложений, госуслуг, рабочей почты и других важных аккаунтов. Не передавайте через них пароли, документы и платёжные данные. Эта подписка предназначена для обхода блокировок, а не для полной анонимности.

Если вам нужна приватность, лучше выбрать проверенный платный сервис или настроить свой сервер. VLESS+Reality на недорогом VPS обычно работает быстрее бесплатных узлов.

Проверить надёжность каждого сервера невозможно. Используйте подписку на свой риск.
