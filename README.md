**[English version](README.en.md)**

Список бесплатных VPN-серверов, который обновляется сам каждый час.

Конфиги берутся из публичных источников на GitHub, склеиваются в одну ссылку и
проверяются: через каждый сервер делается настоящий запрос в интернет, и в
список попадают только те, через которые трафик реально прошёл. У каждого
сервера в названии видно страну, протокол и задержку.

Подписка выходит в двух размерах: основная — около двух сотен отобранных
серверов, полная — все прошедшие проверку, обычно больше тысячи. Основную
клиент пингует за секунды, полная нужна, когда хочется перебрать максимум
вариантов.

Протоколы: VLESS (включая Reality), VMess, Trojan, Shadowsocks, Hysteria2, TUIC.

## Ссылка на подписку

Основная — короткий список, для повседневного использования:

```
https://raw.githubusercontent.com/sakazxc1400-creator/free-vpn-sub/main/output/sub.txt
```

Полная — всё, что прошло проверку:

```
https://raw.githubusercontent.com/sakazxc1400-creator/free-vpn-sub/main/output/sub-full.txt
```

Если `raw.githubusercontent.com` не открывается (в России часто), берите зеркало.
Содержимое то же самое:

```
https://cdn.jsdelivr.net/gh/sakazxc1400-creator/free-vpn-sub@main/output/sub.txt
```

```
https://gh-proxy.com/https://raw.githubusercontent.com/sakazxc1400-creator/free-vpn-sub/main/output/sub.txt
```

Для полной подписки в зеркалах меняется только имя файла на `sub-full.txt`.

Оба зеркала проверены. jsdelivr кэширует ответ на несколько часов, gh-proxy
отдаёт свежую версию сразу.

## Как выглядит список

Серверы отсортированы по задержке, самые быстрые сверху:

```
01. 🇭🇰 Гонконг · vmess · 211ms
02. 🇵🇱 Польша · ss · 288ms
03. 🇬🇧 Британия · ss · 301ms
04. 🇳🇱 Нидерланды · ss · 311ms
05. 🇷🇺 Россия · vless · 340ms
```

В основной подписке одна страна не может занять больше 12 позиций, иначе
половина списка была бы одним датацентром в Гонконге. В полной такого
ограничения нет.

## Подключение

### Windows

Проще всего через [Nekoray](https://github.com/MatsuriDayo/nekoray/releases):
скачайте `nekoray-*-windows64.zip`, распакуйте, запустите `nekoray.exe`.

1. Программа → Настройки → Режим ядра → `sing-box`
2. Сервер → Добавить профиль из подписки, вставьте ссылку, ОК
3. Сервер → Обновить все подписки
4. Выберите сервер сверху списка, `Enter`
5. `Ctrl+Alt+S` включает системный прокси

Вместо Nekoray подойдёт [v2rayN](https://github.com/2dust/v2rayN/releases),
там подписка добавляется в «Подписки → Настроить подписки».

### Android

[v2rayNG](https://github.com/2dust/v2rayNG/releases) или Google Play.

1. `≡` слева вверху → Группы подписок → `+`
2. Вставьте ссылку в поле URL, сохраните
3. `⋮` справа вверху → Обновить подписки
4. Выберите сервер, нажмите кнопку подключения

[Hiddify](https://github.com/hiddify/hiddify-next/releases) тоже хорош, особенно
если нужны Hysteria2 и TUIC. Подписка добавляется через `+` → «Добавить из ссылки».

### iPhone / iPad

Из App Store: Streisand (бесплатно), v2Box (бесплатно) или Shadowrocket (платный).
Везде одинаково: раздел подписок → `+` → вставить ссылку → обновить → выбрать
сервер.

### macOS

[Hiddify](https://github.com/hiddify/hiddify-next/releases) или V2RayXS.
Добавить подписку по ссылке, обновить, подключиться.

### Linux

[Nekoray](https://github.com/MatsuriDayo/nekoray/releases) или
[Hiddify](https://github.com/hiddify/hiddify-next/releases) в виде AppImage.

## Что-то не работает

**Сервер подключается, но интернета нет.** Такое бывает: между проверкой и вашим
подключением сервер мог лечь или упереться в лимит. Возьмите следующий из списка.

**Ни один сервер не работает.** Обновите подписку в клиенте, список меняется
каждый час.

**Подписка не загружается.** Возьмите зеркало из раздела выше. Если и оно не
открывается, скачайте `output/all.txt` вручную и вставьте содержимое в клиент
через «Добавить из буфера обмена».

**Медленно.** Бесплатные серверы перегружены, это нормально. Берите верхние
из списка. Hysteria2 обычно держится лучше остальных на плохих каналах.

## Как это работает

```
sources.txt     список источников
collect.py      главный скрипт: скачать, разобрать, проверить, записать
outbound.py     превращает ссылки vless:// и прочие в конфиг sing-box
probe.py        проверка через sing-box: реально ли ходит трафик
geo.py          определение страны по IP
output/         результат
```

Раз в час GitHub Actions делает следующее.

Качает все источники параллельно, по три попытки на каждый. Понимает и обычный
текст, и base64. Вытаскивает ссылки, отбрасывает мусор: битые адреса, localhost,
приватные подсети, порты вне диапазона.

Дальше дедупликация по адресу сервера, а не по тексту ссылки. Один и тот же
сервер часто лежит в пяти источниках под разными именами, и без этого шага список
был бы наполовину из копий. Из 40 тысяч ссылок остаётся около 10 тысяч разных
серверов.

Потом два этапа проверки. Сначала быстрый TCP-коннект, он за минуту отсеивает
мёртвые адреса. Выжившие идут во вторую проверку: поднимается sing-box, на каждый
сервер вешается локальный прокси, и через него делается запрос к
`generate_204`. Ответ 204 с пустым телом означает, что трафик действительно
дошёл до интернета и вернулся. Проверка идёт батчами по 150 узлов, пока не
кончатся кандидаты или не выйдет отведённое время.

QUIC-протоколы (Hysteria2, TUIC) TCP-фильтр пропускают мимо: у рабочего сервера
TCP-порт закрыт, стучаться туда бессмысленно. Они идут сразу во вторую проверку.

Наконец определяется страна по IP и серверы сортируются по задержке. Всё
проверенное идёт в полную подписку, а в основную отбирается верхушка с квотой
на страну.

Если источники недоступны или ни один сервер не прошёл проверку, скрипт
завершается с ошибкой и не трогает старые файлы. Устаревшая рабочая подписка
лучше пустой.

### Локально

```bash
python selftest.py     # парсеры
python testconv.py     # конвертер ссылок и гео
python testsingbox.py  # валидность конфигов (нужен sing-box)
python e2etest.py      # весь пайплайн на локальном сервере
python collect.py      # собрать подписку
```

Нужен Python 3.9 или новее, зависимостей нет. Для полной проверки узлов положите
рядом бинарник [sing-box](https://github.com/SagerNet/sing-box/releases); без него
скрипт ограничится TCP-проверкой и честно напишет об этом в логе.

### Свои источники

Дописывайте ссылки в `sources.txt`, по одной на строку. `#` в начале строки —
комментарий. Формат содержимого определяется сам.

## Про безопасность

Это важно, прочитайте до того, как начнёте пользоваться.

Владелец сервера видит ваш трафик. Серверы в списке поднимали неизвестные люди,
и никто не знает зачем. Оператор видит, на какие сайты вы ходите, а если подменит
сертификат, то и содержимое соединений.

Отсюда простые правила. Не заходите через такой VPN в банк, на госуслуги, в
рабочую почту. Не отправляйте пароли, документы, платёжные данные. Это инструмент
для обхода блокировок, а не средство приватности.

Если нужна именно приватность, вариантов два: платный сервис с репутацией или
свой сервер. VLESS+Reality на дешёвом VPS настраивается за вечер и работает
заметно быстрее любого бесплатного узла.

Проверить добросовестность этих серверов невозможно. Пользуйтесь на свой риск.
