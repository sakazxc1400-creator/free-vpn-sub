# Free VPN Sub

Собираю бесплатные VPN-конфиги из открытых источников и проверяю каждый живьём: отвечает ли порт,
идёт ли через сервер настоящий трафик, живой ли сертификат и сколько он даёт скорости. Что не прошло,
в подписку не попадает. Делал для себя, выложил, пользуйтесь.

## Клиенты

Windows: Hiddify (проще всего) или Nekoray (переключи ядро на sing-box, иначе hysteria2 и tuic не заведутся).
Android: Hiddify или v2rayNG.
iPhone: Hiddify, Streisand или v2Box.
Linux: Hiddify в AppImage или Nekoray.

Везде одно и то же: добавить подписку по ссылке, обновить профиль, выбрать сервер, подключиться. Hiddify
лучше работает с hysteria2 и tuic, там подписка добавляется через «+» и пункт «добавить из ссылки».

## Что в списке

Серверы идут от самых быстрых к самым медленным, в названии страна, протокол и задержка:

```
01. 🇭🇰 Гонконг · vmess · 211ms · 12ч
02. 🇵🇱 Польша · ss · 288ms
03. 🇬🇧 Британия · ss · 301ms · 8ч
04. 🇳🇱 Нидерланды · ss · 311ms
```

Число вроде `12ч` значит, что сервер отвечает столько часов подряд. У новых отметки ещё нет.

`⚠` стоит у узлов, которые трафик пропускают, но не прошли проверку сертификата: владелец может читать
соединения. Такие попадают только в полную подписку.

В основной подписке от одной страны не больше 12 серверов, чтобы список не получился целиком из одного
датацентра. В полной ограничения нет.

## Как всё работает

```
sources.txt     список источников
collect.py      скачать, разобрать, проверить и сохранить конфиги
outbound.py     превратить ссылку в конфиг sing-box
probe.py        трафик, сертификат, скорость
clashout.py     сборка конфига Clash и Mihomo
notify.py       итог прогона в Telegram
geo.py          страна сервера по IP
mirror/         зеркало подписки на Cloudflare Workers
docs/           сайт для GitHub Pages
```

Дважды в час это запускает GitHub Actions (иногда GitHub задерживает, тогда реже). Скрипт качает источники,
объединяет одинаковые серверы и отбрасывает мусор: localhost, приватные подсети, битые порты. Потом быстрая
проверка портов, а после неё sing-box поднимает по очереди каждый узел и пробует через него пройти в интернет.
Живые узлы получают страну, задержку и проверку сертификата, лучшие попадают в основную подписку.

Прогоны связаны через `history.json`: там отмечено, сколько прогонов подряд сервер отвечает. Те, у кого
набралось 6, уходят в стабильную подписку.

Если новый прогон вышел сильно хуже прошлого (меньше 60% серверов и меньше 400 штук), старые файлы
остаются на месте, а сборка падает с ошибкой. Так сбой у источников не оставит подписчиков с пустым списком.
Обойти это можно переменной `ALLOW_SHRINK=1`, если просадка честная.

Готовые файлы лежат в ветке `data`, в `main` их нет: ветка плоская, там всегда один коммит со свежим снимком,
поэтому репозиторий не растёт на полтора мегабайта за прогон.

## Запуск у себя

```bash
python3 selftest.py     # офлайн-проверки
python3 testconv.py     # конвертер ссылок и определение страны
python3 testclash.py    # сборка конфига Clash
python3 testsingbox.py  # конфиги, нужен sing-box рядом
python3 e2etest.py      # весь сценарий на выдуманных конфигах
python3 collect.py      # полный прогон
```

Нужен Python 3.9 или новее, ничего ставить не надо. Полная проверка серверов требует бинарник
[sing-box](https://github.com/SagerNet/sing-box/releases) рядом с файлами, без него прогон проверит только порты.

Свой источник добавляется строкой в `sources.txt`. Строки с `#` это комментарии.

Итог прогона может уходить в Telegram, для этого нужны секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
в настройках репозитория.

## Про безопасность

Серверы чужие, их владельцы видят, куда ты ходишь, а если подменяют сертификат, то и содержимое соединений.
Такие узлы в основную подписку не попадают, но домены видит всё равно любой владелец. Поэтому не заходи
через эти серверы в банки, госуслуги и важные аккаунты, не передавай пароли и документы. Это штука для
обхода блокировок, а не анонимность. Нужна приватность, поднимай свой сервер, vless+reality на дешёвом VPS
обычно быстрее всей этой бесплатной братии.
