# Free VPN Subscription

Автоматически обновляемая подписка на бесплатные VPN-серверы. Конфиги собираются
из десятков публичных источников, объединяются в одну ссылку, проверяются на
работоспособность и обновляются **каждый час** — чтобы заблокированные адреса
быстро заменялись живыми.

Поддерживаются протоколы: **VLESS (в т.ч. Reality)**, **VMess**, **Trojan**,
**Shadowsocks**, **Hysteria2**, **TUIC**.

---

## Ссылка на подписку

Вставьте эту ссылку в свой VPN-клиент:

```
https://raw.githubusercontent.com/sakazxc1400-creator/free-vpn-sub/main/output/sub.txt
```

> Если `raw.githubusercontent.com` у вас не открывается (частая ситуация в РФ),
> используйте зеркало:
> ```
> https://gh-proxy.com/https://raw.githubusercontent.com/sakazxc1400-creator/free-vpn-sub/main/output/sub.txt
> ```

Дополнительные файлы, если нужен отдельный протокол:

| Файл | Что внутри |
|------|-----------|
| `output/sub.txt` | Всё вместе, base64 — **основная ссылка** |
| `output/all.txt` | То же, но обычным текстом (посмотреть глазами) |
| `output/vless.txt` | Только VLESS |
| `output/vmess.txt` | Только VMess |
| `output/trojan.txt` | Только Trojan |
| `output/ss.txt` | Только Shadowsocks |
| `output/hysteria2.txt` | Только Hysteria2 |
| `output/tuic.txt` | Только TUIC |
| `output/stats.json` | Статистика последнего обновления |

Серверы в списке отсортированы по скорости отклика: **первые в списке — самые быстрые**.
Узлы Hysteria2 и TUIC идут в конце — они работают поверх UDP/QUIC, и замерить их
задержку TCP-проверкой невозможно, поэтому у них в метке стоит `udp` вместо
времени отклика.

## Инструкция по подключению

### Windows

1. Скачайте клиент **[Nekoray](https://github.com/MatsuriDayo/nekoray/releases)**
   (файл `nekoray-*-windows64.zip`) и распакуйте в любую папку.
2. Запустите `nekoray.exe`.
3. В меню: **Программа → Настройки → Режим ядра** выберите `sing-box`.
4. Меню **Сервер → Добавить профиль из подписки**, вставьте ссылку на подписку,
   нажмите **ОК**.
5. Меню **Сервер → Обновить все подписки** — список серверов загрузится.
6. Выделите сервер из начала списка, нажмите `Enter` для подключения.
7. Включите системный прокси: **Ctrl+Alt+S** (или галочка «Режим системного прокси»).

Альтернатива для Windows: **[v2rayN](https://github.com/2dust/v2rayN/releases)** —
шаги те же, подписка добавляется через «Подписки → Настроить подписки».

### Android

1. Установите **[v2rayNG](https://github.com/2dust/v2rayNG/releases)**
   (или найдите в Google Play).
2. Нажмите `≡` слева вверху → **Группы подписок** → `+`.
3. В поле **URL** вставьте ссылку на подписку, сохраните галочкой.
4. Вернитесь назад, нажмите `⋮` справа вверху → **Обновить подписки**.
5. Выберите сервер из начала списка и нажмите круглую кнопку внизу.

Альтернатива: **[Hiddify](https://github.com/hiddify/hiddify-next/releases)** —
поддерживает больше протоколов, добавление подписки через `+` → «Добавить из ссылки».

### iOS / iPadOS

1. Установите из App Store **Streisand**, **Shadowrocket** (платный) или **v2Box**.
2. Откройте приложение → раздел подписок (`Subscribe` / `Config`) → `+`.
3. Вставьте ссылку на подписку и сохраните.
4. Обновите список, выберите сервер, включите подключение.

### macOS

1. Установите **[Hiddify](https://github.com/hiddify/hiddify-next/releases)**
   или **V2RayXS**.
2. Добавьте подписку по ссылке, обновите список, выберите сервер.

### Linux

1. Установите **[Nekoray](https://github.com/MatsuriDayo/nekoray/releases)** или
   **[Hiddify](https://github.com/hiddify/hiddify-next/releases)** (`.AppImage`).
2. Добавьте подписку по ссылке, обновите, подключитесь.

## Если не работает

**Ни один сервер не подключается**
Обновите подписку в клиенте — список меняется каждый час. Затем попробуйте
серверы из начала списка: они отсортированы по скорости.

**Подписка не загружается**
`raw.githubusercontent.com` в некоторых сетях недоступен. Варианты:
- добавьте перед ссылкой зеркало: `https://ghproxy.net/` + ваша ссылка;
- скачайте `output/all.txt` вручную и импортируйте содержимое как текст
  («Добавить из буфера обмена» в клиенте).

**Подключение есть, но интернета нет**
Смените сервер. Проверка в этом проекте подтверждает только доступность порта,
а не то, что сервер реально пропускает трафик.

**Работает медленно**
Бесплатные серверы перегружены — это нормально. Берите те, что выше в списке,
и пробуйте протоколы Hysteria2 / VLESS-Reality: они обычно быстрее и устойчивее.

## Как это устроено

```
sources.txt   → список публичных источников подписок
collect.py    → скачивает, парсит, дедуплицирует, проверяет живость
output/       → готовая подписка (обновляется автоматически)
selftest.py   → юнит-тесты парсеров
e2etest.py    → сквозной тест всего пайплайна
```

Раз в час GitHub Actions:

1. прогоняет тесты;
2. параллельно скачивает все источники (3 попытки на каждый);
3. распознаёт формат — обычный текст или base64;
4. вытаскивает ссылки, отбрасывает битые и нерабочие адреса
   (localhost, приватные подсети, некорректные порты);
5. **дедуплицирует по адресу сервера**, а не по тексту ссылки — один сервер под
   пятью разными именами превращается в одну запись;
6. TCP-проверкой отсеивает мёртвые узлы и замеряет задержку;
   узлы Hysteria2 / TUIC работают поверх UDP, для них делается только
   DNS-проверка, и в подписку они попадают последними;
7. сортирует по скорости и публикует результат.

Защита от порчи подписки: если источники недоступны или живых узлов не нашлось,
скрипт **завершается с ошибкой и не трогает старые файлы**. Лучше слегка
устаревшая рабочая подписка, чем пустая.

### Запуск локально

```bash
python selftest.py   # юнит-тесты
python e2etest.py    # сквозной тест (сеть не нужна)
python collect.py    # собрать подписку
```

Нужен только Python 3.9+. Внешних зависимостей нет.

### Добавить свои источники

Допишите ссылки в `sources.txt` — по одной на строку, `#` для комментариев.
Формат содержимого (текст или base64) определяется автоматически.

## ⚠️ Важно про безопасность

Прочитайте, прежде чем пользоваться.

**Владельцы этих серверов видят ваш трафик.** Это бесплатные публичные узлы,
поднятые неизвестными людьми. Оператор сервера может видеть, какие сайты вы
посещаете, а при наличии подменённого сертификата — и содержимое соединений.

Поэтому:

- **Не входите** через такой VPN в банк, госуслуги, рабочую почту и другие
  важные аккаунты.
- **Не передавайте** через него пароли, документы, платёжные данные.
- Подходит для обхода блокировок при просмотре контента. **Не подходит**
  как средство приватности или защиты.
- Если нужна настоящая приватность — платный VPN с репутацией или свой сервер
  (VLESS+Reality на любом VPS поднимается за 15 минут).

Серверы в списке не проверялись на добросовестность, и проверить их
невозможно. Используйте на свой риск.
