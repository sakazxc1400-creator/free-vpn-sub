        Проверка подписки

        Проверяет доступность ссылки и свежесть списка из браузера. Отдельные серверы так проверить нельзя, для этого в клиенте есть тест задержки.

        Про безопасность

        Прочитай перед использованием.

        Владелец сервера может видеть твой трафик. Эти серверы запускают неизвестные люди, и я не знаю, как они с ним обращаются. Оператор может узнать, какие сайты ты посещаешь. При подмене сертификата он сможет перехватывать содержимое соединений.

        Не используй такие серверы для банковских приложений, госуслуг, рабочей почты и важных аккаунтов. Не передавай через них пароли, документы и платёжные данные.

        Подписка нужна для обхода блокировок, а не для полной анонимности. Если нужна приватность, бери платный сервис или поднимай свой сервер, VLESS+Reality на недорогом VPS работает быстрее бесплатных узлов.

        Поддержать проект
